# Publish this project to GitHub

## Repository setup

1. Sign in to the intended GitHub account.
2. Create a repository named `yugank-studio` (or choose another name), set it **Public** only if you want everyone to see the source, and do not add an extra README, license, or `.gitignore` because this folder already has them.
3. Upload or push the contents of this folder. This repository is source code; it does not automatically publish the web app or connect a domain.

## Before publishing

- Do not add `.env` files, API keys, OAuth tokens, client secrets, account credentials, personal videos/audio, test media, backup ZIPs, or paid style-pack files.
- The `ai-studio/` source keeps its upstream MIT license and attribution. No single license has been selected for the full repository.
- The repo has no GitHub Actions workflow, hosting configuration, user account system, or social uploader.

## Local source folder

Use this folder as the repository root. The `README.md` explains how to run both editor apps locally.
